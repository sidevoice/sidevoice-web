# Integration logos

Each mark is the official icon, taken from the owner's brand page and reduced to a single clean SVG (path data unchanged, viewBox preserved, metadata stripped). Each is used to identify the integration; not an endorsement.

- `openai.svg` — OpenAI Blossom. Source: https://openai.com/brand/ (kit `https://cdn.openai.com/brand/openai-logos.zip`, `OAI_OpenAI-Blossom_Black.svg`). Rules: use exactly as provided, only where it relates to OpenAI services, never more prominent than our own branding, no added colours (black or white only), generous clear space, no busy backgrounds, no implied endorsement; permission can be revoked. `fill="currentColor"`: the theme must resolve it to black or white. Trademark: OpenAI. Used to identify the integration; not an endorsement.
- `codex.svg` — OpenAI's brand page publishes no separate Codex icon for third parties, so this is the OpenAI Blossom (same file and rules as `openai.svg`). Source: https://openai.com/brand/. `fill="currentColor"` (black or white only). Trademark: OpenAI. Used to identify the integration; not an endorsement.
- `elevenlabs.svg` — ElevenLabs "11" symbol. Source: https://elevenlabs.io/brand (`elevenlabs-symbol.svg`). Rules: published in black and white; keep clear space around it (logo: equal to its height); write the name "ElevenLabs" and never imitate the icon with "II" or "11". `fill="currentColor"` (black or white). Trademark: ElevenLabs. Used to identify the integration; not an endorsement.
- `claude.svg` — Claude Spark. Source: https://www.anthropic.com/press-kit (`Claude Spark - Clay.svg`); rules at https://www.anthropic.com/legal/trademark-guidelines. Rules: no changes to colour, proportion or anything else; keep space on every side and use a background that does not hurt legibility; no implied sponsorship or affiliation; use only as Anthropic permits (contact marketing@anthropic.com). Keeps the official colour `#D97757`. Trademark: Anthropic, PBC. Used to identify the integration; not an endorsement.
- `cursor.svg` — Cursor cube (2D). Source: https://cursor.com/brand (kit `cursor-brand-assets.zip`, `General Logos/Cube/SVG/CUBE_2D_LIGHT.svg`). Rules: the page states no usage rules beyond the name "Cursor" (not "Cursor AI" or "Cursor Code"); it publishes the 2D cube in single-colour light (`#26251e`) and dark (`#edecec`) variants. `fill="currentColor"`. Trademark: Anysphere, Inc. Used to identify the integration; not an endorsement.
